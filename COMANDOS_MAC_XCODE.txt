EPICENTER DSP - APP NATIVA SWIFTUI
=================================

La app actual esta en ios-native y en la rama feat/native-ui.
Los ocho ajustes de cola, Hall, Car Audio, inicio y automaticos se agregaron
en el commit f9afc46. El commit 7672833 es anterior a esos cambios.
Esta actualizacion identifica la app como version 12.0.0 (21) en Ajustes.

ACTUALIZAR UNA COPIA EXISTENTE EN LA MAC
---------------------------------------
Ejecuta desde la carpeta raiz del repositorio:

git switch feat/native-ui
git pull --ff-only
git log -1 --oneline
bash ABRIR_APP_NATIVA.command

El comando verifica que el codigo incluya los arreglos, regenera el proyecto
y abre la ruta absoluta de ios-native/EpicenterDSP.xcodeproj.

PRIMERA INSTALACION EN UNA MAC NUEVA
-----------------------------------
1. Instala Xcode desde la App Store y abrelo para instalar sus componentes.
2. En Xcode > Settings > Locations, selecciona Xcode en Command Line Tools.
3. Si no tienes Homebrew, instalalo siguiendo https://brew.sh/.
4. Instala XcodeGen:

brew install xcodegen

5. Clona la rama de la app nativa y abrela:

git clone --branch feat/native-ui https://github.com/EySoyIsaaa/EpicenterIphone.git
cd EpicenterIphone
bash ABRIR_APP_NATIVA.command

EN XCODE
---------
1. Esquema: EpicenterDSP. Destino: tu iPhone o un simulador.
2. Target EpicenterDSP > Signing & Capabilities: selecciona tu Team.
3. Para forzar una recompilacion completa: Shift + Command + K.
4. Ejecuta con Command + R.
5. En la app: Musica > Ajustes > Acerca de debe mostrar 12.0.0 (21).
6. En Epicenter y EQ, Ajuste automatico debe ser la primera tarjeta.
   En la cola, Reproduciendo ahora debe quedar fijo sobre A continuacion.

Para este proyecto SwiftUI no hacen falta pnpm, Node, Capacitor ni CocoaPods.
El flujo pnpm build / cap sync / ios/App/App.xcworkspace abre el proyecto web.
Sus instrucciones historicas estan en:
docs/migration/COMANDOS_MAC_CAPACITOR_LEGADO.txt

SI QUIERES ABRIRLO MANUALMENTE
------------------------------
Desde la carpeta raiz del repositorio:

cd ios-native
xcodegen generate
open EpicenterDSP.xcodeproj
